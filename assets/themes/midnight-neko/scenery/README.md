# Moonlit garden sprites

Built-in imagegen assets in Saya's plum-black, burgundy and silver palette.
The garden is a quiet transparent edge overlay. Bat and particle sprites use
128 × 128 RGBA canvases with proportional silhouettes for small-scale rendering.
No sprite intercepts input. The arrow hotspot remains at its visible tip; native
text, link-hand and resize cursors keep their usual behavior.
